# TendMate marketing media

The finished videos and images for the TendMate marketing posts, kept public so
that Facebook and Instagram can fetch them: Meta's publishing API downloads
media from a URL rather than accepting an upload.

Nothing here is a source. Every file is generated from the master list in the
private product repo and can be rebuilt from it, which is also why this repo
carries a single commit — it is replaced wholesale rather than added to.

    reels/social/    30 vertical videos, 1080x1920, for Reels
    posters/social/        30 images, 1080x1350, the posters as stills
    posters/social/video/  30 videos, 1080x1920: "what this is", then the poster

The music is by Kevin MacLeod (incompetech.com), licensed under Creative
Commons: By Attribution 4.0. The credit travels in the caption of every post.

The cleaning set is always here. Beside it sit the trades whose turn it is,
each with the same three sets under its own folder, and only those: the tree
is replaced whole on every sync, so a trade is published on the days it posts
and not before.
